# phytoncide_project
Started in 2023 to create a better method for analyzing phytoncides using thermal desorption gas chromatography-mass spectrometry. 

For those of you in here just to get access to the xml to tibble file for extracting your TD-GC/MS data, please go to the "many_xml_to_tibble.qmd" and take a poke around there. I have my own data available so you can see my naming conventions and the structure of the data file so when you export it you can edit what you need and work from that as a base.
