General Quality Control Checks and Data Filtering

We need to use the blanks for background subtraction. So I need to find the average amount of the compounds found in the blanks, then remove all observations that are below the blank noise, since these readings would be chocked up to just background noise.

For this analysis all blanks and controls were filtered out for this summary.

finding average concentration of each compound in blanks

since we don’t have a corrected volume for the blanks we are just using the straight “amount” value the agilent system gave us.

#average concentration of blanks
blk_amounts <- dat |>
  filter_out(type != "blk") |>
  group_by(peak_name) |>
  summarize(avg_blank = mean(amount))

Now we only keep the samples that have amounts greater than the blank averages

dat <- dat |>
  filter_out(type == "control") |> #also filtering out controls at this point
  filter_out(type == "blk") |>
  left_join(blk_amounts, by = "peak_name") |>
  filter(amount > avg_blank)

#The amount of times a compound was observed after blank filtering
datcheck <- dat |>
  group_by(peak_name) |>
  summarise(n = n())

Q-value shows how well the m/z matched the ratios provided by the method. Thus, the compounds with a q-value of less than 70 will be filtered out. This ensures that the results we present are accurate.

#filtering out results with a q-value of less than 70

Bar Chart Comparing Detection Frequencies Between the Two Locations

First must combine the two detection frequency tibbles by joining on peak_name

(used AI to help write the pivot long code, showed it a glimpse of the det_freq_fc and based code from it’s reply, did not copy and paste.)

det_freq_fc_long <- left_join(det_freq_f, det_freq_c, join_by(peak_name)) |>
  mutate(freq_f = freq.x,
         freq_c = freq.y) |>
  select(peak_name, freq_f, freq_c) |>
  pivot_longer(cols = c(freq_f, freq_c),
               names_to = "location",
               values_to = "det_freq") |>
  mutate(location = recode(location, freq_f = "forest", freq_c = "city"))

det_freq_fc_long[is.na(det_freq_fc_long)] <- 0 #changing NA to zero so it is plotted
det_barchart_fc <- det_freq_fc_long |>
